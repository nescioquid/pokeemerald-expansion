# Why pokeemerald-expansion?

Still stuck deciding between **pokeemerald-expansion** or pokeemerald for your next ROM hack?

Well, like stated elsewhere, pokeemerald-expansion _already incorporates regular updates from_ pokeemerald, including bugfixes and documentation improvements.

It also supports multiplayer functionality with other games built on pokeemerald-expansion, so you can play along with all of your childhood friends (even if you're not necessarily a child any more 😉)!

Unfortunately, it's not compatible with official Pokémon games. If compatibility with official games is important, _use pokeemerald_.

Otherwise, we can only recommend using pokeemerald-expansion! Ready to [get started](../INSTALL.md)?
