Ready to have some fun? To feel the nostalgia coursing through your veins? You've found the right place!

### Prerequisites

Interacting with the **pokeemerald-expansion** project requires the following:

- **Text editor**: We recommend [VS Code](https://code.visualstudio.com/).
- **GitHub account**: for updating the project and sharing code with others. Create one [here](https://github.com/).
- **Terminal**: The project is built and managed through a command line interface (CLI).

> 📝 Windows users need some additional terminal setup, which we'll cover later.

### Overview

We'll get your next ROM-hacking project going in two steps:

First, we'll **set up your machine**. Installing dependencies (software that our software in turn relies on) and configuring the environment on your computer so that everything runs smoothly.

Then, we'll **set up your repository**. We'll learn about tools like Git and websites like GitHub that make it easy to download, manage, update, and build your ROM hack built on pokeemerald-expansion and share your changes with others (and hopefully get others sharing their changes with you :).
